# RIFF-SPACED

A browser-based guitar riff-writing and transposing tool for heavy, low-tuned, chromatic riff music: sludge, doom, and power metal with a blues-turnaround feel. You see a guitar neck in any tuning (Bb Standard by default), enter and arrange riffs built from dyads and power chords on the low strings, hear them back with the fretboard highlighting each note in sync, and save, load, and export them as JSON, MIDI, text tab, and MusicXML. A Python backend turns recordings of your own playing into riff JSON laid out the way you actually fret it, and an AI layer that understands the owner's style names the dyads, identifies the style, and suggests counter riffs, variations, fingerings, and tunings.

Built in public with Claude Code. Every commit is a lesson: each one explains WHY it was made, WHAT changed, what a newcomer can LEARN from it, and how it was TESTed.
